# Homelessness and Shelter Access in Santa Clara County

## Research Question

How does the geographic distribution of shelters compare with the distribution of people experiencing homelessness across cities in Santa Clara County?

## Project Description

This project explores the relationship between homelessness and shelter availability in Santa Clara County, California.

The dashboard uses 2025 Point-in-Time (PIT) Count data to show the number of people experiencing homelessness in different cities. Larger red circles represent higher PIT counts.

Blue points represent selected shelter locations.

## Data Sources

- 2025 Santa Clara County Point-in-Time (PIT) Count
- Publicly available shelter location data
- LifeMoves
- Family Supportive Housing
